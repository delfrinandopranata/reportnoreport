# Badge

Small marks: outlined mono tags (`rnr-tag`), status as a grey icon plus a word (`rnr-status`, `is-live` adds a pulsing teal dot), mono chips (`rnr-chip`), delta pills (`rnr-delta`), outlined in/out kind marks, mono initials avatars, and keyboard hints (`rnr-kbd`).

Never a tinted green/yellow status pill.
