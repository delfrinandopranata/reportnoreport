# DataTable

Rosters, ledgers and report tables.

## Rules
- Headers: Geist Mono 11px uppercase, `ink-muted`; only the sorted column turns `ink` (`aria-sort`). No sort arrows on every column.
- Rows are hairline-separated; numbers and dates are right-aligned mono (`.num`).
- Status is a grey duotone icon plus a word (`rnr-status`); teams and groups are outlined mono tags (`rnr-tag`). No tinted status pills.
- Density: 10px row padding comfortable, 6px compact.
