# AppearancePanel

Where each person sets theme, surface, density and motion, and admins set the firm accent.

| Control | Attribute | Values |
|---|---|---|
| Theme | `data-theme` | light, dark, bw-light, bw-dark (System follows the OS) |
| Accent (firm) | `data-preset` | default (charcoal / light), ocean, forest, sunset |
| Surface | `data-style` | glass (default), solid, neu |
| Density | `data-density` | comfortable, compact |
| Motion | `data-motion` | full, flat (forced flat under reduced motion) |

Apply before first paint; changes preview live with no Save button.
