# Canvas

The drag-and-drop board for the form, dashboard and report builders: a palette of blocks beside a dotted board with drop zones.

## Rules
- The board is `surface-canvas` with a 16px dot grid (the snap pitch).
- A selected block gets a lumen outline (a glowing line in dark); a hovered drop zone turns its dashed border to `lumen`.
- Every drag has a keyboard and a menu path; moves are announced in a live region.
- On phones the palette becomes a bottom sheet.
